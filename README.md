# Учёт личных трат

Учебный проект по веб-разработке на Go.

Приложение для учёта личных расходов: пользователь добавляет траты,
просматривает список, фильтрует по категориям и датам, видит статистику
и может выгрузить данные в CSV.

Проект выполняется поэтапно в течение семестра.

## Стек

- Go
- `net/http` — HTTP-сервер
- `html/template` — серверный рендеринг HTML
- SQLite (будет подключён на этапе 3)

## Требования

- Go 1.22 или новее
- Git (для работы с репозиторием)

Проверить версию Go:

```bash
go version
```

## Запуск

Из корневой папки проекта:

```bash
go run .
```

Сервер запускается на http://localhost:8080.

Остановить сервер — `Ctrl + C`.

## Структура проекта

```
expenses-app/
├── go.mod
├── main.go
├── internal/
│   ├── handlers/       — HTTP-обработчики
│   └── models/         — структуры данных и хранилище
└── web/
    ├── templates/      — HTML-шаблоны
    └── static/         — CSS, JS
```

## Маршруты

| Путь | Метод | Назначение |
|---|---|---|
| `/` | GET | Список трат |
| `/expenses/new` | GET | Форма добавления траты |
| `/expenses` | POST | Обработка формы добавления |
| `/static/...` | GET | Статические файлы (CSS) |

## Этапы

### Этап 1. Основы Go и HTTP-сервера

- Установлен Go, создан модуль `expenses`.
- Написан HTTP-сервер на `net/http` с маршрутами `/`, `/about`, `/ping`.
- Реализована обработка методов: `GET /ping` → 200 OK + `pong`,
  остальные методы → 405 Method Not Allowed.
- Неизвестные пути возвращают 404.

### Этап 2. Шаблоны, структура проекта и первый интерфейс

- Организована структура проекта: `internal/`, `web/`.
- Создана модель `Expense` (ID, Amount, Description, Date).
- Реализовано хранилище в памяти `ExpenseStore`.
- Созданы шаблоны: `layout.html`, `index.html`, `add.html`.
- Реализованы обработчики списка и добавления траты.
- Настроена раздача CSS через `http.FileServer`.
- После POST выполняется редирект (Post/Redirect/Get).
